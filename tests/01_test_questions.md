# Тестовые вопросы: customer-claims-rag-assistant

**Дата:** 2026-06-20  
**Проект:** FoodFlow (вымышленный сервис)  
**Версия корпуса:** 1.0.0

---

## Назначение документа

Этот файл содержит **60 эталонных пользовательских сообщений** для оценки RAG-ассистента первой линии поддержки FoodFlow. Тесты проверяют retrieval, классификацию, безопасность, handoff и качество проекта ответа **без привязки к exact-match формулировкам**.

## Правила использования

- Каждый тест имеет уникальный ID `T001`–`T060`.
- Ожидаемые семантические результаты — в `tests/02_expected_answers.md`.
- Фактические результаты прогонов записываются **позже** в `tests/03_test_results.md`.
- Улучшения фиксируются в `tests/04_improvement_log.md`.
- Тесты **не требуют** запуска retrieval или LLM на этапе подготовки корпуса.
- В сообщениях используются **вымышленные** данные; реальные персональные сведения не применяются.
