## Общие сведения

База знаний состоит из 10 документов. Исходные файлы размещаются в `data/01_raw/` (формат `.txt`), очищенные версии — в `data/02_clean_markdown/` (формат `.md`).

**Статус на 2026-06-20:** документы `01–03` подготовлены и повторно проверены после независимого аудита. Документы `04–06` подготовлены, очищены и проверены по реестру; ожидают независимого аудита. Документы `07–09` **подготовлены, очищены, проверены по реестру; приняты после независимого аудита**. Документ `10` **не подготовлен** (файл пустой).

Метаданные clean-файлов согласованы со схемой `docs/04_metadata_schema.md`. Содержание согласовано с `docs/05_business_rules_registry.md`.

## План FAQ: 45 вопросов и ответов

Документ `10_customer_faq` будет содержать **ровно 45 пар** «вопрос — ответ». План сгруппирован по категориям; формулировки ответов должны опираться на документы 01–09 и реестр `docs/05_business_rules_registry.md`.

### Соглашения по FAQ

| Правило | Описание |
|---------|----------|
| Количество | Ровно **45** пар Q&A |
| Markdown-якоря | **Не используются** |
| Связь с политиками | Через метаданные `related_documents` и поле `section` |
| Новые правила | FAQ **не создает** правил, отсутствующих в профильных политиках |
| Глоссарий | Термины определяются в `01_service_overview`, отдельный документ глоссария **не создается** |

*(План вопросов по категориям сохранен без изменений — см. предыдущую версию инвентаризации; наполнение отложено до этапа 04–10.)*
